Each Tuesday (and Wednesday for hospitalisation forecasts based on case ensemble), one of the hub maintainers merges latest forecasts. This is usually done via the following steps:

1. Open the pull request containing the submission
2. Verify that checks have run and are passing. When you scroll down, you should see a green mark. 

![image](https://user-images.githubusercontent.com/10783929/179529195-da881937-ba6c-422c-96a9-85b7d2366e10.png)

3. Verify that only relevant files are modified

![image](https://user-images.githubusercontent.com/10783929/179542784-4487e3c7-4e29-4ea1-8ef6-f3c89f103bf7.png)

4. Click on the previsualisation link to ensure the forecasts don't look completely off

![image](https://user-images.githubusercontent.com/10783929/179542924-2032ebe7-df89-4614-add8-630975cc6bcf.png)

5. Merge the submission (by clicking on "Merge pull request", **not** "Squash and merge", or "Rebase and merge")

![image](https://user-images.githubusercontent.com/10783929/179529195-da881937-ba6c-422c-96a9-85b7d2366e10.png)
