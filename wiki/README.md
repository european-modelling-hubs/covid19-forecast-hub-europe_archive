# Wiki snapshot

This directory is a static snapshot of the project's GitHub wiki, vendored into
the main repository so it is captured in the archival release and its Zenodo
record. The live wiki lived at a separate git repository
(`covid19-forecast-hub-europe_archive.wiki.git`) and is not otherwise included
in release source archives.

Start at [Home.md](Home.md). Internal `[[wiki-style]]` links refer to the other
Markdown files in this directory.
